First release of **redistransport** — a Redis Streams transport for the
[Mercure](https://mercure.rocks/) SSE hub. Scales the hub horizontally
via per-node consumer groups on a shared Redis Stream, with built-in
history replay, presence, and multi-backend support (Redis, Valkey).

## Install

```caddyfile
mercure {
    transport redis {
        url redis://localhost:6379
        # see the README for the full directive reference
    }
}
```

Or as a library:

```bash
go get github.com/lzrf0cuz/mercure/redistransport@v0.0.1
```
